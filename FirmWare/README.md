# Firmware

This directory contains checked-in factory or recovery firmware images for the board.

These binaries are not generated by CI and are not treated as source projects by the build workflow. Use them only when the product documentation or support flow calls for flashing a released binary image.

Source-built firmware artifacts are produced by the `Build Examples` workflow from maintained ESP-IDF and Arduino source projects. Use the helpers in `releases/` to package local build outputs or download CI artifacts.
